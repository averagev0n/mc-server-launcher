# Цифровая подпись программы

Без подписи Windows SmartScreen показывает при первом запуске «Windows защитила ваш компьютер»,
а антивирусы чаще ошибочно ругаются на программу. Подпись это убирает.

## Бесплатно: SignPath Foundation (для открытых проектов)

SignPath Foundation бесплатно подписывает программы с открытым исходным кодом.
Точные и актуальные условия — на сайте: https://signpath.org

Что нужно сделать (это делает владелец репозитория, за него это сделать нельзя):

1. **Выбрать открытую лицензию** и добавить файл `LICENSE` в репозиторий —
   без OSI-одобренной лицензии (например, MIT или GPL-3.0) заявку не примут.
   Выбор лицензии — решение автора: она определяет, что другим можно делать с кодом.
2. **Подать заявку** на signpath.org, указав репозиторий
   `https://github.com/averagev0n/mc-server-launcher`.
3. **Перенести сборку в GitHub Actions.** SignPath подписывает только то, что собрано
   автоматически из открытого кода (так они проверяют, что подписывается именно этот код).
   В проекте уже есть проверка `.github/workflows/ci.yml` — к ней добавляется шаг сборки
   и шаг отправки на подпись по инструкции SignPath.
4. После одобрения в описании программы и на сайте нужно будет указывать,
   что подпись предоставлена SignPath Foundation (это их условие).

## Платно: собственный сертификат

- **Обычный (OV) сертификат** — примерно 200–400 $ в год. Предупреждение SmartScreen
  пропадёт не сразу, а когда программу скачает достаточно людей.
- **EV-сертификат** — дороже, обычно только для организаций, убирает предупреждение сразу.

Подпись подключается в `package.json` → `build.win` (параметры electron-builder для
сертификата) — после этого `npm run release` будет подписывать файлы сам.

## Без подписи

Предупреждение со временем появляется реже, когда программа набирает «репутацию».
Можно ускорить: отправить файл на проверку в Microsoft —
https://www.microsoft.com/wdsi/filesubmission (раздел «Software developer»).
